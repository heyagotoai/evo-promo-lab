# Laboratorium promocji i ewolucji

Interaktywne prezentacje z sesji o algorytmach ewolucyjnych:

- **Cztery linie lodów** — Euforia / Retro / Pycha / Flirt, promo do −50% albo 2+2, rotacja 12 tygodni
- **Dzień handlowca** — które sklepy w 6 godzin
- **Kolejność wizyt** — dlaczego „najbliższy punkt” przegrywa
- **OneMax** — najprostszy algorytm genetyczny

Model liczbowy (COGS, popyt) jest syntetyczny — do kręcenia gałkami, nie do listingu.

## Lokalnie

```bash
npm install
npm run dev
```

## Deploy

Vercel (statyczny Vite + HashRouter).
